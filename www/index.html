Implemented Features

HTTP/1.1 Support

Fully implemented GET and HEAD request handling with proper HTTP/1.1 responses, status codes, and headers.

Thread Pool

Complete thread pool implementation with worker threads, task queue, and proper synchronization using mutexes and condition variables.

Bounded Blocking Queue

Thread-safe bounded blocking queue with push(), try_push(), and pop() operations for connection management.

Backpressure (HTTP 503)

Returns HTTP 503 Service Unavailable when the request queue is full, preventing resource exhaustion.

Path Security

Safe path handling using realpath() to prevent directory traversal attacks (../etc/passwd blocked).

Static File Serving

Serves static files (HTML, CSS, JS, images, PDFs) with proper Content-Type detection and Content-Length headers.

Command-Line Arguments

Full CLI support: --port, --docroot, --threads, --queue with sensible defaults.

Error Handling

Comprehensive error responses: 400 (Bad Request), 403 (Forbidden), 404 (Not Found), 405 (Method Not Allowed), 503 (Service Unavailable).

Debug Logging

Console logging with timestamps showing connection details, file requests, and error conditions.
